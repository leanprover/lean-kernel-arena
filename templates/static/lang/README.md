Logos of the checkers' implementation languages, shown in the checker table.
They are referenced from `LANGUAGES` in `lka.py`, keyed by the `language`
field of the checker YAML.

Sources:

* `cpp`, `csharp`, `fortran`, `haskell`, `java`, `ocaml`, `python`, `rust`,
  `solidity`, `tex`: [Devicon](https://github.com/devicons/devicon) v2.16.0
  (MIT license), the `-original` variants.
* `aver`: `docs/logo-mark-light.svg` from
  [jasisz/aver](https://github.com/jasisz/aver) (MIT license).
* `vow`: the icon from [vow-lang.com](https://vow-lang.com), scaled to 64×64.
* `lean`: redrawn after the stacked L∃∀N mark on
  [lean-lang.org](https://lean-lang.org).
* `cobol` (a punched card) and `x86` (a CPU chip) have no official logo and
  were drawn for this site.

Logos are drawn into a square box of the same size whatever their aspect
ratio, so a square source file looks best.
